# NTM: Space

NTM: Space for Minecraft 26.2, with Fabric and NeoForge builds: an addon to NTM Next, built against the NTM
release named by `hbm_version` in `gradle.properties`.

NTM: Space was created by JamesH_2 and Mellow; this is movblock's port to Minecraft 26.2.

## Build

Requires JDK 25.

```sh
./gradlew build
```
